# Devapriya Suresh V: portfolio

Plain HTML, CSS and JS. No build step.

## Add your images
Save photos in the `images/` folder with exactly these names (lowercase, `.jpg`):

| File | Where it appears |
|---|---|
| `profile.jpg` | Hero portrait (gem-cut frame, portrait photo works best) |
| `about.jpg` | About section |
| `project-thesis.jpg`, `project-realmip.jpg`, `project-mlem.jpg`, `project-stent.jpg`, `project-drowsy.jpg`, `project-vehicle.jpg` | Selected work |
| `gallery-1.jpg` to `gallery-6.jpg` | Runway, events and sport |

Preview before saving: open `index.html`, click any "Add image" box and pick a photo. This preview lives only in your browser. Add `?edit` to the URL to replace images that already exist. To publish, put the real file in `images/` and push.

## Edit your details
- LinkedIn and GitHub links: bottom of `index.html` (search for `your-profile` and `your-username`).
- Resume: `assets/Devapriya_Suresh_Resume.pdf`.

## Deploy on GitHub Pages
1. Create a repo and upload everything in this folder (so `index.html` sits at the top level).
2. Settings, Pages, Source: "Deploy from a branch", branch `main`, folder `/ (root)`.
3. Your site goes live at `https://<username>.github.io/<repo>/`.

File names are case-sensitive on GitHub, so `Profile.JPG` will not load as `profile.jpg`.
